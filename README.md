# HTML-CSS-PORTFOLIO
## Overview
My **Personal Portfolio** website was built using HTML and CSS. The website showcases my projects, skills, background, and contact information in a colourful and responsive design.

***The goal of this project was to practice front-end development concepts while creating a professional online presence to display my work and learning journey as a software developer.***


## Features
My website features:
- Responsive website
- Hero section with call-to-action button
- Projects showcase
- Skills and Tools
- An **about me** section
- Contact form powered by **Formspree**
- Links to my LinkedIn and GitHub accounts

  
## Technologies Used
- HTML5
- CSS3
- Font Awesome Icons
- Google Fonts
- Formspree

## Responsive Design

- Stacking navigation elements vertically
- Adjusting hero section layout
- Reorganizing the About section content
