# Portfolio Website

## Overview
This **Personal Portfolio** website was built using HTML and CSS. The website showcases my projects, skills, background, and contact information in a colourful and responsive design.

***The goal of this project was to practice front-end development concepts while creating a professional online presence to display my work and learning journey as a software developer.***


## Features
My website features:
- Responsive website with navigation bar
- Hero section with call-to-action button
- Projects showcase using card layout
- Skills and Tools section that features my skills according to categories
- An **about me** section
- Contact form powered by **Formspree**
- Links to my LinkedIn and GitHub accounts

  
## Technologies Used
- **HTML5**
  - Semantic elements such as header, section, footer, etc.
  - Anchor links for page navigation.
  - Forms with form controls such as input, textarea, button, etc.
  - Classes and IDs'.
  - Image embedding.
- **CSS3**
  - Flexbox layout for alignment and structure
  - Responsive design using media queries
  - Hover effects and transitions
  - Box model
- **Font Awesome Icons**
- **Google Fonts**
- **Formspree**


## How to View the Project
### Steps:
1. **Download the repository** - https://github.com/AngelaSolomons/Portfolio-website.git
   - Click on the link above or go to the repository
   - Click the "Code" button
   - Download as a ZIP file
2. **Extract or unzip the ZIP file**
3. **Inside the folder, look for a file called index.html**
4. **Open the index.html file in any modern web browser**
5. **View the website**

## Challenges I faced
One of the main challenges was making the layout responsive across different screen sizes, especially in sections with side-by-side content. Aligning elements properly while keeping the design consistent took multiple adjustments and testing.


## What I learned
I believe I improved my skills in layout design, responsiveness, and structuring a full multi-section website from scratch.
